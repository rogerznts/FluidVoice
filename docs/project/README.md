# Project

`/mosk-pm` (João), no modo planner, escreve aqui: o plano vivo do projeto e as atualizações datadas.

## Estrutura

- `plan.md` — plano vivo, em linguagem não-técnica.
- `update-YYYYMMDD.md` — registros datados de progresso.

## Base vs spec

- **Base** (esta pasta) — acompanhamento do projeto como um todo.
- **Per-spec** (`docs/specs/{id}/project/`) — acompanhamento de uma feature específica.
