## Base vs spec

- **Base** (esta pasta) — o produto como ele é hoje.
- **Per-spec** (`docs/specs/{id}/prd-delta.md`) — a mudança que uma spec propõe ao PRD. Promoção para cá é `manual` por padrão: alguém lê e aplica.
