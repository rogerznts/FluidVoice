# Discovery

`/mosk-analyst` (Maria) escreve aqui: pesquisa de mercado, análise competitiva, briefs e resultados de brainstorming.

## Base vs spec

- **Base** (esta pasta) — pesquisa que vale para o projeto inteiro, independente de qual feature está em andamento.
- **Per-spec** (`docs/specs/{id}/discovery/`) — pesquisa que só existe por causa de uma feature específica.

Na dúvida, escreva na spec. É reversível: no arquivamento, um artefato com front-matter `promote:` sobe para cá.
